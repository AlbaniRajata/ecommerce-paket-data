# 📱 E-Commerce Paket Data

E-Commerce Paket Data adalah website e-commerce untuk pembelian paket data internet dengan tampilan modern dan pengalaman pengguna (UX) yang sederhana dan efisien. Project ini dibuat untuk memenuhi tes teknis internship sebagai Frontend Developer.

---

## ✨ **Fitur Utama**

- 🔐 **Login:**
  - Form login dengan validasi dan penyimpanan lokal.

- 🏠 **Landing Page:**
  - Hero section dengan CTA untuk mengajak user login/mulai.

- 🗂️ **Paket Data:**
  - Menampilkan daftar paket data yang tersedia.
  - Modal konfirmasi pembelian dan notifikasi berhasil.

- 📦 **Paket Data Aktif:**
  - Tampilkan paket data yang sedang aktif beserta masa berlaku.

- 📜 **Riwayat Transaksi:**
  - List paket data yang sudah dibeli & diaktivasi.

- 🎨 **Desain & UI:**
  - Menggunakan Ant Design dengan kustomisasi warna.
  - Desain mengikuti [Figma](https://www.figma.com/design/eVs2y3eag9ety23DiZTAuU/E-Commerce-Paket-Data).
  - Konsisten, dengan font Poppins.

---

## 🛠 **Tech Stack**

- **Frontend:**
  - ReactJS (Hooks, Router)
  - Ant Design
  - Axios

- **Backend (Mock API):**
  - json-server

---

## 🔄 Alur & Waktu Pengerjaan

Project ini adalah simulasi e-commerce untuk pembelian paket data. 
Alurnya: user mulai dari halaman landing → login → dashboard untuk membeli & melihat paket data → aktivasi paket di halaman Paket Data → cek riwayat di halaman Riwayat Transaksi.
